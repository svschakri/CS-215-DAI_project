## How to Run

```bash
# 1. Clone the repository
git clone https://github.com/svschakri/CS-215-DAI_project.git
cd CS-215-DAI_project

# 2. (Optional) create a virtual environment
python3 -m venv venv
source venv/bin/activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Open and run the analysis notebook
jupyter notebook analysis.ipynb
```

Run all notebook cells top-to-bottom. `data_clean.py` only needs to be re-run if you replace the
CSV with the original raw Kaggle file:

```bash
python3 data_clean.py
```
